# WellSync Project Guidelines

- **Language Conventions:**
  - All source code (variable names, comments, string resources except specific AI instructions) MUST be written in English.
  - All git commit messages MUST be written in English.
  - The AI model prompts/instructions should request responses in Japanese as currently implemented.

- **Git Workflow:**
  - Do NOT automatically push changes (`git push`) unless explicitly instructed to do so by the user. Always ask for permission or wait for a direct command.
